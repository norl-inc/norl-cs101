# norl-cs101

**AIの裏側で何が起きているか、分かるようになる。**
Claude Code が先生役をする、完全初心者向けのコンピュータサイエンス入門です。自分のペースで進められます。

[English](README.md)

エンジニアを育てるコースではありません。構文の暗記もしません。
ターミナル、ファイル、Web、ネットワーク、コンテナ、AIモデルについて、**Claude があなたのために何をしているか分かり、確かめられる**ところまで学びます。

## はじめかた

1. [Claude デスクトップアプリ](https://claude.ai/download) を入れて、**Code** タブを開く
2. Claude にこう頼む：「github.com/norl-inc/norl-cs101 を書類フォルダにクローンして開いて」
3. `/start` と打って、言語を選んで、あとは先生についていく

コマンドは **アプリの中のターミナルパネル** で打ってください（ターミナル.app や iTerm ではなく）。そうすると先生があなたの画面を見て教えられます。

| コマンド | 何をする |
|---|---|
| `/start` | 言語を選ぶ、Mac の状態を確認、スタート |
| `/next` | 次のレッスンへ |
| `/hint` | ヒント（3段階。答えそのものは出ない） |
| `/check` | 自分の作業を確認してもらう |

## 中身

[CURRICULUM.md](CURRICULUM.md) を見てください。ターミナル → Python → Web → プログラムが動く場所 → AIのしくみ → Claude を使いこなす → 卒業制作（自分の手で作ったアプリを、Claude にもう一度作らせて見比べる）。

コマンドや略語の「元の英語」は [COMMANDS.md](COMMANDS.md) にまとめてあります。
