---
name: check
description: 今のレッスンの課題ができているか確認して講評する。合格なら progress.md を更新する。
---

1. `progress.md` の `current` と、そのレッスンの README の「チェック」節を読む。
2. レッスンフォルダに `check.sh` があれば `bash <そのパス>` で実行する。無ければ「チェック」節の条件を、ターミナルパネルとファイルを読んで確かめる。
3. 講評は短く、やさしく：
   - 合格：良かった点を1つ具体的にほめる。README の「AIとの関係」を伝える。`progress.md` の `done` に追加する。次のステップの欄で、ボタン `次のレッスンへ` / `ここで休む` を出す。
   - 不合格：どこが違うかを1つだけ伝える（直し方は書かない）。次のステップの欄で、ボタン `ヒントがほしい` / `自分で直す` を出す。
4. 合否に関係ない細かい点（大文字小文字、スペースなど）は指摘しない。
