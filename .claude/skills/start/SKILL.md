1. `progress.md` が既にあれば、内容を読んで「続きから再開する？」と聞き、再開なら `/next` と同じ動きをする。
2. 言語を聞く：日本語 / English。
3. 受講者の Mac の状態を自分で確認する（受講者には打たせない。これは準備なので）：
   - `sw_vers -productVersion`、`python3 --version`、`git --version`、`brew --version`
   - 足りないものがあっても今は入れない。必要になるレッスンで一緒に入れる、と伝える。
4. `playground/` フォルダを作る。ターミナルパネルに「練習」という名前のタブを、このリポジトリのフォルダで開いておく（受講者には打たせない。0-1 で初めて使う）。
5. `progress.md` を作る：

```markdown
# progress
- language: 日本語
- current: 0-1
- done:
- notes:
```

6. 一言でコースの目的を伝える：「AIに任せるが、何を任せたかは分かっている人になる」。進め方も一言で：「先生が1つずつ案内します。終わったらボタンを押してください。分からないことがあったら、なんでも聞いてね」。
7. `lessons/00-intro/01-wow/README.md` を読んで、0-1 を始める。まず今日のゴールを2〜3行で伝え（ボタン：`はじめる`）、押されたらステップ1を見せる（CLAUDE.md の「1ステップずつ導く」のとおり）。準備の作業（progress.md やタブ）の話はしない。
