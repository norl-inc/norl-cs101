1. `progress.md` の `current` と、そのレッスンの README を読む。
2. ターミナルパネルの最近の内容と、`playground/` の関係ファイルを読み、どこで詰まっているか見当をつける。
3. この会話でこの課題のヒントを何回出したかで段階を決める：
   - 1回目：方向性だけ（「どのコマンドの仲間を使えばいいか」）
   - 2回目：使う道具の名前と、その使い方の一般例（課題とは別の例で）
   - 3回目：ほぼ答え。ただし最後の1か所は受講者に埋めさせる
4. 3行以内で返す。最後に「やってみて、できたら『やった』と送ってね」。
