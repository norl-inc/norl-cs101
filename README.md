# norl-cs101

**Understand what happens behind the AI.**
A hands-on, self-paced computer science course for complete beginners, taught by Claude Code itself.

[日本語はこちら](README.ja.md)

This is not a course for becoming a software engineer. You will not memorize syntax.
You will learn enough about terminals, files, the web, networks, containers and AI models to know what Claude is doing when it works for you — and to check it.

## How to start

1. Install the [Claude desktop app](https://claude.ai/download) and open the **Code** tab.
2. Ask Claude: *"Clone github.com/norl-inc/norl-cs101 into my Documents folder and open it."*
3. Type `/start`, choose your language, and follow along.

Use the **Terminal panel inside the app** (not Terminal.app or iTerm) so your tutor can see what you type.

| Command | What it does |
|---|---|
| `/start` | Pick your language, check your Mac, begin |
| `/next` | Go to the next lesson |
| `/hint` | Get a hint (three levels, never the full answer) |
| `/check` | Check your work |

## What's inside

See [CURRICULUM.md](CURRICULUM.md): terminal → Python → web → where programs run → how AI works → using Claude well → a capstone where you build an app by hand, then watch Claude build the same one.

Lessons are written in Japanese; if you choose English in `/start`, your tutor teaches in English.

Where command names come from (`cd` = change directory, …): [COMMANDS.md](COMMANDS.md).
